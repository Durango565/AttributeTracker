# AttributeTracker Demo (Web-first, NBA2K-style)

This repo contains three responsive GUI concepts for a self-improvement attribute tracker with strong game-like styling.

## Concepts
- `ui-concepts/concept-a`: Neon dashboard with radial meters.
- `ui-concepts/concept-b`: Card + badge progression layout.
- `ui-concepts/concept-c`: Split-pane quest/challenge HUD.

## Shared Demo Features
- 1–1000 attribute ratings for: Fitness, Focus, Discipline, Creativity, Social, Finance, Sleep, Learning.
- Daily check-ins, weekly trend mini-bars, streaks.
- Progression systems: levels, XP, badges, archetypes, attribute caps, quests/challenges.
- Local-only state + mock account profile.
- Custom skill creation (e.g., Cooking, Sports).

## Run
Open any `index.html` directly, or run:

```bash
python3 -m http.server 4173
```

Then visit:
- `http://localhost:4173/ui-concepts/concept-a/`
- `http://localhost:4173/ui-concepts/concept-b/`
- `http://localhost:4173/ui-concepts/concept-c/`
